# Backend CIOE

Archivos para el Web Service de Render.

Variables de entorno necesarias:
- DATABASE_URL: URL interna de PostgreSQL de Render.
- FRONTEND_ORIGIN: https://sistema-camaras-cioe.onrender.com
- ADMIN_PASSWORD: contraseña inicial del administrador.

Comandos Render:
- Build Command: npm install
- Start Command: npm start

IMPORTANTE: no publiques DATABASE_URL ni ADMIN_PASSWORD dentro de index.html o GitHub.
